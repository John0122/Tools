# Target Web design

## Purpose and scope

Target Web 是局域网 HTTP 方法与外链检测靶机。主要操作是选取接口、真实发出请求、阅读响应，以及按分类访问可扫描的链接和资源样例。保留现有 Target Web 标题、系统字体、浅蓝灰色调及深色模式。页面使用原生 HTML、CSS、JavaScript，无组件库和构建框架。

## Layout and hierarchy

页面最大宽度 1200px，顶部为标题、协议入口和当前地址。桌面正文为接口列表与响应面板两栏，间距 24px；响应面板保持在视口顶部 24px。800px 及以下改为单列，点击请求时滚动到响应面板，并提供返回列表链接。接口是带分隔线的完整可点击行。

外链二级目录使用 13 行分类列表；每个三级页包含面包屑、分类导航和技术特征分区。桌面分类导航位于左侧，800px 及以下转为正文前的紧凑导航；原始 HTML 保留链接与资源地址，方便静态扫描。域名分类页展示受控外站地址；IP 分类页展示本站 IP，按内站、公网外站、局域网其他设备分区。

## Tokens and source of truth

运行时 token 唯一来源为 `frontend/css/style.css` 的 `:root`；此文件记录设计意图。新增界面必须复用这些 CSS 变量，不添加平行主题配置。

所有 HTML 页面的标签页图标统一为用户指定的 Tabler `brand-feedly` SVG，24×24、描边色 `#0d8e91`，通过 `link[rel=icon]` 的 `data:image/svg+xml` URL 内嵌。首页直接声明；目录、分类、落地、嵌入、暗链目标和跳转页由 `scripts/generate-link-pages.py` 的公共模板声明，不增加图标资源请求。

## Components and state ownership

`index.html` 拥有页面结构、导航、列表容器、结果区域；`app.js` 拥有目录加载、列表按钮、请求状态、响应渲染。列表内容唯一来源是后端 `/api`。禁止用预置数据模拟响应。所有动态文字通过 `textContent` 设置。

接口行使用原生 button，`aria-pressed` 表示当前选中项。请求中禁用重复发送，结果区 `aria-busy` 配合独立状态文本。加载目录失败可刷新；请求失败、超时可重试；HEAD 空正文与 CONNECT 预期 501 显式解释。TRACE/CONNECT 标注后端代发，并区分入口 HTTP 状态和目标响应状态。

`scripts/generate-link-pages.py` 拥有分类 HTML、辅助落地文档和样例清单，`js/link-lab.js` 拥有真实请求、动态 DOM、表单状态和 WS 连接交互。Fetch/XHR 超时 8 秒；原生表单在命名 iframe 展示实际响应；跨站表单的 HTTP 状态不伪装为可读取结果。WS 明确连接、回显、关闭与错误状态。

资源访问链接统一使用 `target="_blank" rel="noopener"`，包含静态、动态和隐藏样例；三级页标题区告知新标签页行为，文件由浏览器按附件响应下载。分类、面包屑与返回入口用于页面导航，资源链接用于访问测试目标。

检测样例允许三种有意隐藏：display、透明和屏外定位，仅作用于标记出的样例容器，隐藏链接退出键盘焦点序列。正常折叠内容保留可见 summary 作为对照。域名分类页包含站内 404、站外 410；IP 分类页使用内站 IP 的暗链与 404/410，公网和局域网目标不预设状态。失效资源的浏览器错误是预期数据；普通导航和交互不得借此省略错误反馈。演示字体仅影响字体样例段落。

IP 分类复用现有章节和原生链接。公网链接固定为 `https://1.1.1.1/cdn-cgi/trace`，直接保留在静态 HTML 与清单中。本站地址由部署配置注入；另一套局域网服务的 IP 在部署终端提示中输入，默认生成 `https://<IP>:38443/`，支持 `--lan-ip` 参数及已有入口环境变量。回车可跳过，非法地址重新输入；未配置时显示文字说明，不渲染空 href。已配置链接在新标签页打开，配置状态在容器启动时确定，不加载域名演示脚本及其元数据，也不自动访问目标。

## Accessibility and verification

保留语义化标题、导航、跳转链接、键盘焦点和 live status。代码块可键盘聚焦滚动；窄屏不依赖横向滚动阅读。状态同时使用文字和颜色，不使用动画传递关键信息，滚动即时完成以避免运动干扰。交付前运行静态 UI 审计、浏览器实际点击九种方法，检查窄屏、键盘操作和失败恢复；静态审计不能替代浏览器验证。
